# AskPupkin — дз 2

Django-проект на основе статической вёрстки дз1.

Реализованы представления, именованные маршруты, наследование шаблонов,
подшаблоны и пагинация списков вопросов.
Для локального запуска:
- Python 3.13;
- pip и venv.

Для запуска в контейнере:
- Docker;
- Docker Compose.

## Настройки окружения

Перед первым запуском создайте файл .env на основе .env.example.


Для DJANGO_SECRET_KEY укажите собственное значение.
.env содержит локальные настройки и исключён из Git.
.env.example содержит названия переменных и заглушки и хранится в Git.
## Локальный запуск в Linux/macOS — Bash

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Создайте и настройте .env, как описано выше.

Проверка и запуск:

```bash
python manage.py check
python manage.py runserver
```

Открыть: http://127.0.0.1:8000/

Для остановки сервера нажмите Ctrl+C.


## Данные и пагинация

На этапе ДЗ2 используются данные-заглушки из questions/views.py.

Общая функция paginate находится в core/pagination.py.
Списки новых, лучших вопросов и вопросов по тегу отображаются
по 10 элементов на странице.

Пример второй страницы:

http://localhost:8000/?page=2


## Запуск через Docker Compose

Необходимы Docker и Docker Compose.

Перед первым запуском создайте файл .env на основе .env.example
и укажите собственное значение DJANGO_SECRET_KEY.
Если .env уже настроен, используйте существующий файл.

Если сайт уже запущен локально на порту 8000, остановите его сочетанием
Ctrl+C в терминале локального сервера.

Проверьте конфигурацию:

```
docker compose config --quiet
```

```
docker compose up --build
```

После запуска откройте: http://localhost:8000/

Для остановки нажмите Ctrl+C в терминале, где запущен Docker Compose.

Для удаления контейнеров и сети проекта выполните:

```
docker compose down
```

## Страницы

- index.html — главная
- question.html — страница вопроса
- ask.html — создание вопроса
- login.html — логин
- signup.html — регистрация
- profile.html — настройки профиля
- tag.html — вопросы по тегу


Маршрут вопросов по тегу имеет вид /tag/<tag_name>/.
Например: /tag/black-jack/.
Если подходящих вопросов нет, отображается сообщение об отсутствии вопросов.
